# Plan de ejecución: gt-hu-031-rotulos-acciones-seguimiento

Solo para tareas `medium`/`large`. Es una cola persistente de pasos: márcalos
al avanzar para que, si la sesión se corta a medio camino, la siguiente sepa
exactamente dónde retomar sin releer todo desde cero.

- [ ] Paso 1 — Derivar un rótulo de acción específico a partir de la etapa y
  el destino existente, incluyendo `Revisar solicitud`.
- [ ] Paso 2 — Renderizar el rótulo en la tabla y añadir pruebas para las
  etapas cubiertas y el destino de revisión.
- [ ] Paso 3 — Ejecutar las pruebas específicas, revisar formato y registrar
  el cierre.
