# Formatos de referencia

Esta carpeta conserva copias de referencia de los formatos recibidos para el
proyecto. Antes de versionarlos se sanearon los datos personales:

- Las capturas de pantalla se sustituyeron por marcadores de contenido
  redactado.
- Se eliminaron los registros de empresas y contactos del libro de convenios;
  se conservaron las etiquetas y estructura de la hoja.
- Se retiraron metadatos de autoría, correos y números de identificación de
  los documentos de Office. El nombre de la persona firmante en la carta de
  presentación se sustituyó por un texto genérico.

Por ello, estos archivos no sustituyen los originales institucionales ni deben
usarse como documentos oficiales. Los originales con datos personales deben
conservarse fuera del repositorio.
