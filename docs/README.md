# Documentación del proyecto

Este directorio contiene los artefactos del producto; la memoria operativa de
Continuum permanece en `.ai/`. La documentación se organiza por versión para
conservar el alcance y los entregables de cada etapa.

| Carpeta | Contenido |
|---|---|
| `v1.0/requerimientos/` | Requisitos, alcance y decisiones confirmadas |
| `v1.0/casos-de-uso/` | Actores, flujos y criterios de aceptación |
| `v1.0/backlog/` | Épicas, historias, prioridades y dependencias |
| `v1.0/sprints/` | Objetivos, alcance y revisión de cada sprint |
| `v1.0/planeacion/` | Documentos de referencia y planeación |
| `v1.0/formatos/` | Formatos de referencia saneados |
| `v1.0/entregables/` | PDFs de backlog y plan de sprints |
| `v1.0/manuales/` | Manuales de usuario y operación |
| `v1.1/Planeacion/modificaciones.md` | Solicitudes que servirán de entrada para el backlog de v1.1 |

`v1.0/` conserva la documentación del prototipo cerrado. Las modificaciones
para la siguiente versión se refinan en una tarea de Continuum antes de
convertirse en backlog aprobado.
