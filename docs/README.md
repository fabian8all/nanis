# Documentación del proyecto

Este directorio contiene los artefactos del producto; la memoria operativa de Continuum permanece en `.ai/`.

| Carpeta | Contenido |
|---|---|
| `requerimientos/` | Requisitos, alcance y decisiones confirmadas |
| `casos-de-uso/` | Actores, flujos y criterios de aceptación |
| `backlog/` | Épicas, historias, prioridades y dependencias |
| `sprints/` | Objetivos, alcance y revisión de cada sprint |
| `manuales/` | Manuales de usuario y operación |

El propósito general está registrado en `requerimientos/vision-inicial.md`; las responsabilidades de los roles y el flujo siguen pendientes. La tarea activa `.ai/tasks/inicio-requerimientos-backlog/` guía el descubrimiento. Las hipótesis del backlog no son requisitos aprobados.
