# Plan de trabajo inicial

**Estado:** propuesta por etapas, sin fechas ni duración de sprint asignadas.

| Etapa | Trabajo | Resultado |
|---|---|---|
| Descubrimiento | Recibir responsabilidades de coordinador, asesor, alumno y empresa; aclarar documentos, flujo y restricciones. | Visión y mapa del proceso validados. |
| Requisitos | Definir alcance, reglas, criterios de éxito, casos de uso y criterios de aceptación. | Requisitos y casos de uso revisados con la persona solicitante. |
| Refinamiento | Desglosar y priorizar historias; identificar dependencias, riesgos y estimaciones con el equipo. | Backlog ordenado y entendible. |
| Planificación | Acordar capacidad, cadencia y objetivo del primer sprint con el equipo. | Plan de sprint realista y medible. |

No fijar compromisos de fecha ni comenzar funcionalidades de negocio antes de validar alcance y disponibilidad del equipo. La siguiente entrada requerida es la definición del proyecto sobre las tareas de cada rol.
